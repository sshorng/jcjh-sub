# RDQ 需求規格：課表外觀美化

## 一句話任務
只調整**教師課表與班級課表**的視覺外觀，讓課多時仍簡約、清楚、好看，且只上下捲動。

## ✅ 已確認
- 課程格左側藍線是主要改版原因，移除現有呈現方式（Ⅰ／Ⅲ）。
- 固定課程格高度，文字過長顯示省略號，點擊沿用現有行為查看完整內容（Ⅲ）。
- 課程、空堂、代課／調課／超鐘等狀態要有清楚層次；特殊狀態維持標籤顯示（Ⅰ／Ⅱ）。
- 上方班級列、日期標題列、左側節次時間列、午休列與空堂格一起規劃（Ⅰ／Ⅱ）。
- 可上下捲動，不可出現橫向捲動；原則上只改 CSS，不改資料與功能（Ⅰ／Ⅱ）。

## ❓ 假設（未確認，已採預設值）
- 以桌機／平板寬度優先，窄畫面以縮小間距與換行維持可讀性。
- 正常課程採白底與中性細框；空堂採淡灰低對比底；狀態色集中在標籤，不以整格大面積上色。
- 班級選擇列可自動換行，不以水平捲動解決班級過多。

## ➕ 已採納（象限Ⅳ）
- 建立共同的課表視覺層級：班級列／日期列／節次列／課程格／狀態標籤。

## ❌ 排除項
- 不保留現有藍色左線、空堂虛線框與過度裝飾性邊界。
- 不改課表資料、計算、點擊流程或狀態判斷。

## 📋 一段式需求規格
請在 **school-substitution-sys** 中，以 CSS 為主重新設計教師課表與班級課表。課程格移除現有藍色左線，改用白底、中性細框、適度圓角與輕微層次；空堂使用淡灰低對比區塊，與有課格清楚分開。上方班級選擇列、日期標題列、左側節次／時間列與午休列要有一致且不簡陋的排版層級。課程格固定高度，長文字以省略號處理，點擊仍查看完整內容；代課、調課、超鐘等特殊狀態沿用標籤顯示。五天欄位需在可用寬度內排下，只允許上下捲動，不得產生橫向捲動。

## ✔ 驗收條件
- [ ] 教師與班級課表都沒有現有藍色左線與空堂虛線框。
- [ ] 空堂、有課、代課／調課／超鐘標籤三者能一眼區分。
- [ ] 課多時課格高度一致、長文字省略，點擊完整內容功能不受影響。
- [ ] 常用寬度下五天欄位不產生水平捲軸，只能上下捲動。
